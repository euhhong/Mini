## 집 N 계약

새 손잡이 하나 `T1159_HOME_N=1`, 기본 끔. 호스트가 집 N을 제공하고 econ은 집의 성장·침상·곳간 식에 쓴다.

집 N = econ 명부 − 집 영토 밖의 실제 전쟁·토벌 원정 몸 수. 출정 표지만 붙고 집결 중인 몸, 귀환해 집 영토에 닿은 몸은 집 N에 든다. 보통 일터 주민은 원정으로 세지 않는다. pid 중복은 한 번만 센다. 몸/좌표/영토를 모르는 항목은 임의로 원정 처리하지 않는다. 호스트가 없는 랩은 종전 N이다.

| 갈래 | 적용 |
|---|---|
| 로지스틱 | 비율·성장항, 식량 밖 K 대조, 건강·행복·위신 성장항, 하루 변동 상한 |
| K | 땅·식량 용량은 기존 정본, 연료 수요와 1인 연료 K 분모는 집 N |
| 주거 | 집 증축 목표·하루 건설량·침상 출생 문. 그날 태어난 사람은 즉시 집 침상을 차지한다 |
| 곳간 | 겨울 출생 문 N+1, 옛 굶주림 문턱 N×3 |
| 총 명부 | POP_MAX는 전체 인구, 원정 군량·먹기·옷·도구 장부는 기존 정본 |

- 전용 하네스: 실제 밖의 원정만 제외, 귀환 즉시 포함, 미설정=끔, 호스트 없는 랩 보존.
- 실제 econ 틱에서 명부20·집4·침상5일 때 켬은 정확히 1명 출생, 끔은 출생을 막는다. 집 몸0이면 과거 출생 누적분도 출생하지 않는다.
- 끔 기준선 3/3·전쟁 팔 기준선 대조 및 전쟁 팔 세 시드 출생·굶음·인구 비교는 남았다.
