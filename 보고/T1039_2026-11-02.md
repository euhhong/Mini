1. **[재민 · PM — `walk` 켬 기본]** `walk` 는 켬 기본 후보다(재민 11-01 "걸어간 몸이 단"). 다만 판 자(하루 250 ms · 하루 걸음 16 px)에선 해체 단이 167 ~ 529날 길 위에 있어 판 자 띠의 약탈이 띠 밖으로 내려간다(§3). 운영 하루로는 같은 길이 0.03 ~ 0.09날이다. 켬을 기본으로 둘 때 판 자 기준선을 새로 낼지(그 자는 걸음을 못 잰다 — T765 6) · 판 자에서만 끌지가 PM 칸이다.
2. **[재민 · 캐논 — 가는 동안 단이 하는 일]** 정본에서 찾은 꼴은 T765 길 위 장부다(길 위 사람은 econ 밖 — 먹기 · 늙기 0). 그대로 따라 가는 단은 `GANGS` 밖이다: 습격 0 · 토벌 표적 0 · 절망 이탈 합류 0 · 유지비 · 굶음 0 · 결성 비축은 닿는 날. 길 위 먹기 · 늙기(판정대기 3-a)와 같은 열린 칸이다 — 가는 단이 먹고 줄지 · 길 위에서 토벌당할 수 있는지.
3. **[재민 · 캐논 — 전장 시신]** ④ — 교전에서 쓰러진 출정 몸은 교전 끝 `_warEndFight` 가 누운 시간 없이 거둔다(`_warDespawnPid`). 마을에서 죽은 몸은 T590 이 `corpseMs` 동안 눕힌다. 판 자(T941)에선 쓰러짐과 거둠이 한 틱이다. 전장 시신도 누운 몸 문법을 따를지.
4. **[정보 · T590]** `_bx.vanish`(`server/villages.js:1393`)는 선언만 있고 쓰는 줄이 0 이다 — "T590 `vanish` 0" 은 늘 0 이다. 몸 없이 사라짐을 셀 칸이면 `_warDespawnPid` 같은 문에 붙여야 하고, 아니면 지울 칸이다.
5. **[PM · 정보 — 단 몸 늦음]** 단 사람이 도적 하루 밖(T476 실전투 토벌 `server/villages.js:7147`)에서 줄면 단 몸은 다음 도적 하루 끝까지 선다(판 자 세 갈래 같음 · 최대 3 · 10 ~ 44날). 몸 둘은 아니지만 "몸 ≤ 사람" 이 하루 안에서 깨진다.
6. **[PM — 다시 뜸]** `walk` 에서 몸은 비영속이다: 길 위 단은 다시 뜨면 몸 없이 장부만 남고(닿으면 단 몸 0 — 새 몸 0 을 지킨다), 이미 선 단은 부팅 실체화가 종전처럼 은거지 곁에 세운다(마을 몸 부팅 재스폰과 같은 규칙 · `syncBodies(true)`). 다시 뜬 판에서 몸을 어떻게 이을지는 몸 영속(T747 · T833) 쪽 칸이다.
7. **[정보 — 절망 이탈 몸]** 절망 이탈(`desert`) 몸은 갈래와 무관하게 종전 그대로다(은거지까지 걸어 닿으면 거둠 — 기존 단 몸이 min(3, n) 이면 몸 둘 0). `walk` 에서 걸어 선 단의 몸이 모자랄 때(몸 상한 1 — 걸어온 몸 0) 이탈 몸을 단 몸으로 받을지는 카드 밖이다. 단 몸 상한 3(`BDT_BODY_PER_GANG`)도 그대로다 — 걸어온 몸이 셋 넘으면 넘는 몸은 닿은 날 종전 닿음 회수.
