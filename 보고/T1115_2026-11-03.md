## ① WebKit 실기 — WebKitGTK 2.52.6(`scripts/t1115-vv-webkit.js --browser webkit`)
* 길: `apt-get install webkit2gtk-driver xvfb` → `Xvfb` → `WebKitWebDriver` → W3C WebDriver 로 MiniBrowser 를 몹니다. UA 는 `AppleWebKit/605.1.15 … Safari/605.1.15` 입니다. 자는 Playwright WebKit 이 있으면 그것을 먼저 쓰고, 없으면 이 길로 갑니다. 크롬과 **같은 쪽 안 측정 함수**를 넣습니다.
* 서버 자료로 엽니다(Shift+G 가 부르는 `openVillageView` · 시세 기준 나무). 탭 넷을 찍고, 열기 · 다시 열기 · 탭 처음 · 다시 볼 때를 재고, 열림 · 닫힘 rAF 를 3초씩 재고, 사진에서 대비를 잽니다.

## ② 열기 비용 줄이기
1. **판 그림 캐시**(`52-u-oseok.js` `engraveCanvas`): 판 글자 · 판 선 · 테두리 · 막대는 같은 열쇠면 떠 둔 판 그림 한 장을 옮기기만 합니다. 열쇠는 글자 · 글꼴 · 크기, 또는 모양 · 폭 · 높이 · 굵기 · 찬 몫에 화소 배율과 판 값(`C`)을 더한 것이라, 같은 열쇠면 같은 화소입니다. 비우는 때는 글꼴이 늦게 오거나 DPR 이 바뀔 때(`redrawAll`), 그리고 `document.fonts` `loadingdone` 입니다. 칸 수 상한은 400 이고, 오래 안 쓴 것부터 버립니다. 셈은 `Oseok.cacheStats` 에 있습니다.
2. **통째도 바뀐 칸만**(`villageViewOnMessage`): 같은 마을을 닫았다 다시 열면 서버는 통째(`full:true`)를 다시 보냅니다. 이제 칸마다 JSON 을 견줘 바뀐 칸을 읽는 판만 다시 짓습니다(T1103 의 바뀐 칸 표 그대로). 그래서 다시 열기 받아 그리기가 62 → 0.4ms 입니다. e2e ⑤b 는 머리 · 대시보드 판이 그대로인지(같을 때) 새로인지(다를 때), 그리고 수가 새 통째의 서버 값인지 봅니다.
3. **입히기 읽기 · 쓰기 묶기**(`vvSkin`): 판 글자(쓰기만)를 먼저 다 입히고, 판 자리 · 막대 · 선 · 테두리 · 버튼 크기를 한 번에 읽은 뒤 씁니다. 종전에는 칸마다 `clientWidth` 를 읽고 캔버스를 쓰기를 번갈아 해 칸 수만큼 배치를 다시 셈했습니다(판 선 8.5 → 5.5ms).

크롬 A/B — 같은 자 · 같은 세계 · 판마다 새 서버 · 세 판 × 크기 둘(`보고/T1115/chromium-AB-3판.txt`) · 여섯 값 가운데:

## §회부
1. **[재민]** 맥 Safari 실기 — 이 상자엔 맥이 없습니다. WebKitGTK 는 같은 엔진이지만 그래픽 뒷단(macOS CoreGraphics · Metal)과 창 합성이 다릅니다. 글꼴은 모듈이 담은 woff2 라 같습니다. 재민 Safari 에서 `?T1070_VILLAGE_VIEW=1` · 마을 앞 Shift+G 로 탭 넷을 한 번 보면 됩니다. Playwright WebKit 은 내려받기 호스트를 허용하면 같은 자가 그것을 먼저 씁니다.
   ```bash
   node scripts/t1115-vv-webkit.js --browser webkit
   ```
2. **[PM 판정]** 손잡이 켬 기본. 근거는 위 표입니다. 남는 것은 셋입니다. 촌장 "일 맡기기"(새 화면에 없음), 회관 누르기가 마을 화면을 열지(지금은 회관 재고 판), 옛 판 UI 하네스 넷의 갈래입니다.
3. **[재민 · T1105 회부 2 그대로]** `dash.foodDays`(먹을 것 며칠치) · `dash.fuelCov` · `fuelShort`(오늘 땔감 몫)가 서버에 실려 오지만 화면에는 아직 없습니다. "겨울 준비" 머리 아래 둘지, "오늘 땔감"으로 따로 둘지가 판정이라 이 카드에서 배치하지 않았습니다. 정해지면 `vvAdapt` 한 곳에서 합니다.
4. **[정보]** land1039 합침에서 고정 자료 `village-view.json` 의 집터 자재 줄 `give`(T1103)가 빠졌습니다(T1105 쪽으로 풀림). 서버는 그대로 싣고 있어 고정 자료만 되돌렸습니다. 끔 판 e2e ⑨ 가 이것으로 빨개졌습니다.
5. **[정보]** 첫 열기 판 글자 60ms 안팎은 캐시가 안 드는 몫입니다(처음 그리는 글자). 나눠 그리기는 T1083 회부 3 그대로입니다.
