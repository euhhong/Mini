- Node와 브라우저 번들·랩 두 판의 글자를 맞췄다. 인라인/번들 대조 16 PASS / 0 FAIL, 특산 직업 하네스는 OFF 및 ON 각 6개 단언 통과.

## 측정 정의와 재현

- 800일 정본 JSON을 원본 gzip과 SHA256으로 보존했다. OFF는 기존 `계측/T1152_판/main_<seed>.json`과 JSON 및 바이트 모두 3/3 같다.
- 기존 관측기의 `starvingDays=0`은 없는 `_fdDay`를 읽은 잘못된 값이다. 이를 결과에서 제외했다. 위 기아 사망은 정본 `_deadTot`의 누적치다.
- 기존 `trade.foodImported`는 food/cooked_food/fish/meat만 세는 제한된 원수량이다. 곡물이 포함된 전체 식량 수입으로 사용하지 않는다.
- 보충 `t1156-flow-observe.js`는 실행한 교역 줄의 양방향 품목을 기존 kg·foodPer로 환산한다. 구매 시점의 양이며 아직 돌아오는 중인 짐도 포함한다. 보충 6판이 원래 정본 결과와 바이트 같은지 확인한다.
- 공개 관측기는 포기한 교역을 제외한다. 실제 보충 판은 바구니 OFF여서 과거 관측기와 이 조건 차이는 없다. 실행한 관측기 원문과 해시도 자료에 보존한다.
- `scripts/t115x-measure.py T1156 --source <고정사본> --out <자료> --node <Node22> --workers 1`로 OFF/ON 각 3시드를 재현한다. 고정 사본에 의존성을 연결하고 Node 22.23.0을 썼다.
