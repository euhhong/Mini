# 지시 T1134 — 행복 = 목표로 다가가는 값(배너로드 사기 꼴) · 인구만큼 불만 (★재민 11-03 판정 ⑤ ㄱ)

**세션:** S10(T1113 을 한 세션) · **베이스:** main(land1042 뒤) · **가지:** `batch/happy-target-1104` · 커밋 `[승인 대기 · T1134]`

## 판정(★재민 11-03)

재민: "행복이 무언가에 영향은 미쳐야 한다 · 낮을 때 벌칙도 있어야 — 지금은 불행하게 지내는 게 오히려 이득 아닌가 · 행복을 낮추는 요인이 너무 부족하다" → "배너로드식으로 — 인구만큼 불행점수를 높이면 · 인구 적은 마을은 행복하게 시작" → **ㄱ 인구 그대로(선형)**. 그리고 "같은 조건이면 30 에서 시작하든 70 이든 100 이든 시간이 지나면 완전히 같은 값으로 수렴" — 이것이 이 모델의 정의다.

## 모델

* **목표 행복** `h*` (날마다 다시 셈 · 현재값을 읽지 않는다):
  * `h* = 0.5 + 좋은 것 − 인구 항 − 겪은 일`
  * 좋은 것 = 지금 `_computeVillageStats` 항 그대로(창고 품목 포화 · 음식 가짓수 · 여가 · 추위 옷 · 옷감 품질 · 가죽 물건) — 무게는 그대로, 기준만 0.5 위로 옮긴다.
  * **인구 항 = c · N**(ㄱ 선형). c 는 손으로 정하지 않는다 — 아래 게이트에서 세 값을 재 보고에.
  * 겪은 일(계단 하나씩 · 반감기 30날 · T1075 의 빚 · 굶어 죽음 항을 여기로 옮김): 굶주림 날 · 굶어 죽음(1/N) · 전사 · 약탈당한 곳간 · 징발로 집 비움. 수는 T1075 꼴(1/N · 반감기)에서 유도 — 새 손수 0.
* **실제 행복** `h` 는 목표로 다가간다: 하루 `h += (h* − h) · (1 − 2^(−1/T))` · 반감기 `T` 손잡이 하나(배너로드 사기처럼 멀수록 빨리 움직인다).
* **범위 0 ~ 1**(배너로드 0 ~ 100 꼴) — 지금 위 상한 없음(최대 ≈2.0)을 닫는다.
* **같은 조건 → 같은 값** — 출발값은 끝값에 영향이 없다(아래 하네스로 증명).

## 효과(낮을 때 스스로 고쳐지는 쪽)

* 출생: 지금 성장 항 `(h − 0.5) × 0.6 × N × POP_GROWTH_RATE` 그대로(이미 낮으면 준다).
* **이주**: `h < 0.25` 이면 하루 작은 몫이 둘레의 더 행복한 마을로 떠난다(받을 곳 없으면 안 떠남 · 소멸 금지 — 몸은 걸어서 간다 · 기존 이주 문이 있으면 그것 하나 · 사본 금지). 마을이 줄면 인구 항이 줄어 다시 오른다 → 마을마다 **자기 부가 감당하는 크기**에서 멈춘다.
* T1113 ① 촌장 지정 거부 · ② 출정 거부 — 이 판의 효과로 켬 후보(새 `h` 로 판단).
* T1113 ③ 품질 감점은 **끔 그대로**(가난 → 불행 → 품질 ↓ → 더 가난 — 스스로 고쳐지지 않는 고리).
