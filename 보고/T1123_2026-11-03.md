## §2 ② central 정적 응답 — `server/static-serve.js`(손잡이 `T1123_STATIC_CACHE`)

* 켬:
  * 모든 파일에 `ETag`(내용 sha1)와 `Last-Modified`(mtime)를 붙인다. `If-None-Match` · `If-Modified-Since` 가 맞으면 304(몸 0)다.
  * `?v=<그 파일의 내용 sha1>` 로 온 요청은 `Cache-Control: public, max-age=31536000, immutable`(카드가 준 수)이다.
  * 그 밖(`?v=` 없음 · 옛 값)은 `no-cache` 다. 늘 다시 묻고, 안 바뀌었으면 304 다.
  * ★html 의 `?v=` 값을 내보낼 때 **그 파일의 내용 sha1** 로 갈아 쓴다.
    * 까닭: `index.html` 의 `?v=5h0` 는 배포마다 안 바뀌는 고정 글자였다. 그 값에 immutable 을 걸면 다음 배포의 js 를 한 해 동안 못 받는다.
    * 이제 값은 내용이 정한다. 배포해서 바뀐 파일만 새 주소가 된다.
    * html 자체는 붙잡지 않는다. 가리키는 js 가 바뀌면 `?v=` 가 따라 바뀐다(하네스 ⓓ).
    * 마크업은 손대지 않았다.
  * js · json · css · html · svg · txt 는 gzip 이다(처음 한 번 눌러 붙잡는다 · 내용이 바뀌면 다시 누른다).
    * `terrain.json` 991 KB → 216 KB · `00-const.js` 130 → 49 KB · `style.css` 47 → 13 KB.
  * 형식 표에 json · webp · svg · jpg · ogg · m4a · woff2 · glb 를 더했다(종전엔 octet-stream).
  * `/terrain.json` 길도 같은 함수를 지난다.
* 끔(`=0`): 종전 머리 그대로다 — `no-cache, no-store, must-revalidate` · `Pragma` · `Expires` · 형식 표 다섯 · 압축 0 · `?v=5h0` 그대로(하네스 ⓔ).
