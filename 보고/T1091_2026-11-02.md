## §1 코드 — 어느 N 인가

* `sim/economy-sim.js:3868` `const N = v.npcs.length` — 원정 간 징발자(`_warDraft`)가 든다. 이 N 이 쓰이는 곳은 넷이다.
  * 하루 감소 상한: `:4252` `maxDelta = N × POP_MAX_DELTA_PCT(0.06)`
  * 로지스틱: `:4225` `r·N·(1 − (N/K)^θ)`(r 0.04 · θ 4)
  * 건강 · 행복 · 위신 항: `:4238 ~ 4242` 각 `× N`
  * 굶주림 문턱: `:4229` `totalFoodEquivalent(v) < N × 3`
* 먹는 사람 수는 다르다: `:3872` `_t423EatN(v, N)` 이 짐꾼(`_warPack`)을 뺀다.
* 기근 죽음은 징발자를 건너뛴다(`:4315` `if (v.npcs[i]._warDraft) continue`).
* **K 는 명부 N 을 직접 안 쓴다.** `K = min(slotK, prodK, fuelK)`(`:4220`) 중 둘은 땅에서 나온다. `slotK = totalFoodSlots(v)` 는 `jobCapacity(v)` 의 땅 자리이고, `prodK` 는 그 자리의 용량 흐름 + 수입 EMA 다. `fuelK` 의 1인 수요는 `fuelNeed ÷ N` 인데, `fuelNeed = N × FIREWOOD_PC × (…) + 제련꾼 × SMELT_FUEL_PER`(`:4129`)라 N 이 약분된다. 제련 몫만 명부 N 으로 나뉜다.
* 관찰기 줄로 확인: 로지스틱 칸(`_dpDebug.logi`)을 명부 N · K · r · θ 로 다시 셈하면 판 넷 2,170 마을-날 모두 맞다(K 반올림 폭 ± 0.05 안 · 599/599 · 607/607 · 392/392 · 572/572). econ 이 쓴 N 은 명부다.
