## §3 화면이 읽을 필드(세션12 · T1103 `vvAdapt`)
```
store.rows[].use         num   — 하루 수요(소비 EMA). 키가 없으면 소비 0.
store.rows[].priceUp     bool  — 값 ▲ 래치(30날 평균 대비 급등이 선 뒤 풀리기 전). 키가 없으면 장부가 아직 판정하지 않는다 — 그리지 않는다.
store.rows[].priceDown   bool  — 값 ▼ 래치(같음).
store.short.rows[]       { res, ko, qty, daysOf, use? } — 모자란 것(곳간이 바닥난 물건 포함 · qty 0 · daysOf 0). withheld = 뭉뚱그린 것이라 뺀 줄 수.
store.glut.rows[]        같은 꼴 — 남는 것.
store.priceMoves.rows[]  { res, ko, type: 'PRICE_SPIKE'|'PRICE_DROP', day, ago, line } — 지난 days(30)날 값 오르내림 사건(새것부터 · line 하십시오체).
(그대로) rows[] { res, ko, qty, daysOf, short, glut } · shortDays · glutDays · withheld
(키 없음 · 회부) 날마다의 시세 · 어제보다 · 모자란 까닭 문장
```
* 이름 맞춤: T1103 `vvAdapt` 는 창고에 아직 없는 칸을 바라지 않는다(T1103 보고 "칸 표 — T1105 와 맞출 이름"에 창고 줄 0 · "어제보다" 칸은 걷었다). 새 키는 서버 칸 `store.*` 아래라 화면 꼴(`vvAdapt` 의 `S.short` 등)과 부딪치지 않는다 — 화면은 지금 `raw.store.rows` 만 읽는다(`52-v-village-view.js:65-68`).
* ⚠지금 화면의 "모자란 것"(`S.short` = `rows[].short` 거르기 · `:68`)은 곳간이 바닥난 물건을 못 본다 — `store.short.rows` 로 갈아 끼우면 든다(클라 몫 · 회부 T1116 3).
* 값이 없으면 키가 없다 — `use`(소비 0) · `priceUp`/`priceDown`(창 못 채움). 빈 글자 · 0 으로 채우지 말 것.
